# 事件注册与本地结算契约

每个正式事件只存在于一个内容文件；`config_id` 全局唯一。运行时由 `src/ui/event-registry.ts` 合并、索引并拒绝重复 ID。

受控事件必须登记 `config_id`、`title`、`event_type`、`trigger_action_ids`、前置/阻断条件、参与者、设施、优先级、一次性标记、最大有效回合、模型投影键、剧情大纲、必经节点、禁止偏离、允许结果及固定结尾、下游解锁和失败恢复方式。

模型只接收当前事件的最小投影、剧情大纲、必经节点、禁止偏离和固定结尾。成本、幂等键和本地结算细节不投影给模型；`action_id -> result_id` 始终由本地登记表决定。

同一事件拥有多个入口结果时，必须使用 `action_results` 为每个入口登记唯一 `result_id`、目标形态/提出者、路线效果和固定结尾。确定性成本与时间推进登记在 `local_settlement`；运行时只向模型投影本次入口对应的选择与固定结尾，不投影成本处理器或其他入口的结局。
