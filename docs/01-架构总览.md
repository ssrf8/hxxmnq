## 1. 项目概览

| 项目 | 说明 |
|---|---|
| 卡名 | 未开之花（汤泉）V1.0.6 |
| 卡文件 | `V1.0.6.png`（PNG + tEXt `chara` chunk 嵌入角色数据） |
| 前端控制器 | `零层美化/index.js`（1.2 MB 压缩 Vue 打包脚本） |
| 变量系统 | MVU（MagVarUpdate）+ zod |
| 世界书 | 382 条，多前缀分类，含初始变量与输出格式指令 |
| 运行载体 | SillyTavern（酒馆）+ 酒馆助手（Tavern Helper / JS-Slash-Runner） |
| 玩法 | 楼层化经营：老板 / 游客 / 服务员 三种模式，每日安排、经营日报、AI 人才市场 |

### 1.1 整张卡的分层

```
┌─────────────────────────────────────────────────────────┐
│  SillyTavern 酒馆主页面 (window.parent)                  │
│  ┌───────────────────────────────────────────────────┐  │
│  │ 酒馆助手 (Tavern Helper / JS-Slash-Runner)          │  │
│  │ 提供全局 API：eventOn / getVariables / generate /  │  │
│  │ replaceVariables / injectPrompts / sendMessageAs / │  │
│  │ setChatMessage / createChatMessages / saveWorldInfo│  │
│  │ reloadCurrentChat / updatePresetWith ...           │  │
│  └───────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────┐  │
│  │ MVU (MagVarUpdate) 变量系统                         │  │
│  │ stat_data / display_data / zod 全局 z              │  │
│  └───────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────┐  │
│  │ 聊天楼层 (#chat)                                    │  │
│  │  └─ 虚拟 UI 楼层 .mes[data-tq-visual-zero]          │  │
│  │     └─ #tangquan-game-ui-host                      │  │
│  │        └─ iframe(srcdoc) ← 前端控制器零层美化       │  │
│  │           └─ Vue3 + Pinia 单页应用                  │  │
│  └───────────────────────────────────────────────────┘  │
│  普通 AI 消息楼层与 UI 楼层共存                          │
└─────────────────────────────────────────────────────────┘
```

**核心思路**：前端控制器把自己包装成"楼层里的一个 UI 楼层"——把 Vue 应用装进 iframe，把 iframe 装进一个克隆出来的消息楼层（`data-tq-visual-zero`），追加到 `#chat` 末尾（详见 [06-渲染机制与前后端分工.md](06-渲染机制与前后端分工.md)）。通过 iframe 的 `window.parent` 访问酒馆助手全局 API，从而：
- **上行**：写变量、写消息、注入提示词、保存世界书、发起 AI 请求；
- **下行**：订阅事件（`tavern_events.MESSAGE_SENT / MESSAGE_RECEIVED` 等）、轮询/变更监听变量、解析 AI 回复中的特殊标签。

## 2. 运行环境与依赖

### 2.1 必需组件

| 组件 | 作用 | 缺失后果 |
|---|---|---|
| SillyTavern | 宿主 | 无法运行 |
| 酒馆助手（Tavern Helper / JS-Slash-Runner） | 提供前端可调用的全局 API（`eventOn`、`generate`、`replaceVariables` 等） | 前端初始化直接失败 |
| MVU（MagVarUpdate）扩展 | 变量系统：`stat_data` / `display_data`，负责 `<UpdateVariable>` 解析 | 变量不更新，玩法失效 |
| zod（全局 `z`） | MVU 与 index.js 都用**全局自由变量 `z`**（不 import） | 脚本解析 schema 时 ReferenceError |

> ⚠️ `z` 在 `index.js` 和 `magvarupdate.js` 中都是**自由全局**：没有 import、没有定义、没有挂载。它依赖外部环境（酒馆助手或 MVU 扩展）注入全局 `z`。改造时不要试图在本地 import zod 替代，除非同步改掉所有使用点。

### 2.2 前端 bundle 依赖链（已在本地 vendor 化）

`index.js` 顶部通过 CDN import（原 `https://testingcf.jsdelivr.net/npm/.../+esm`），已全部改写为本地相对路径 `vendor/`：

```
vue@3.5.39（runtime-dom / runtime-core / reactivity / shared）
pinia
klona
@vue/devtools-api@8.1.5（devtools-kit / shared）
birpc@2.9.0
hookable@5.5.3
perfect-debounce@2.1.0
MagVarUpdate bundle（vendor/magvarupdate.js，动态 import 目标）
```

### 2.3 卡片如何加载前端（发布 → 导入 → 执行全链路）

**卡内声明**：`data.extensions.tavern_helper.scripts[0]`（酒馆助手字段，`setting_field='tavern_helper'`）内容：

```json
{
  "type": "script", "enabled": true, "name": "未开之花", "id": "ce05002f-...",
  "content": "import 'https://testingcf.jsdelivr.net/gh/sanmingyue/tavern_dist@tq-v1.0.6/dist/汤泉/脚本/零层美化/index.js'",
  "button": { "enabled": true, "buttons": [ { "name": "打开未开之花", "visible": true }, ... ] },
  "data": { "tangquanSaveRuntime": {...}, "tangquanUiSettings": {...} }
}
```

- `content` 是**一行 import 语句**，指向远端仓库；`data` 可携带脚本自定义状态（这里存了存档槽位、UI 设置）；
- `button.buttons` 定义角色卡面板按钮（"打开未开之花"可见等）。

**加载执行机制**（JS-Slash-Runner 源码，`src/panel/script/iframe.ts` + `predefine.js`）：

```
1. 角色卡 data.extensions.tavern_helper 读入（zod 校验 CharacterSettings）
2. 脚本渲染成隐藏 iframe：<iframe id="TH-script--{name}--{id}" v-show="false">
3. iframe srcdoc = createSrcContent(content)：
     <script src="parent_jquery_url">   → 父窗口 $ (jQuery)
     <script src="predefine_url">       → 注入父窗口全局
     <script type="module">             → content（import 语句）在此执行
       import 'https://.../零层美化/index.js'
4. predefine.js 把酒馆主窗口全局注入本 iframe 的 window：
     _ / EjsTemplate / TavernHelper / YAML / showdown / toastr / z (zod)
     SillyTavern（getContext + writeExtensionField 覆盖）、Mvu（getter 转发）
5. 因此 index.js 在 iframe 里"裸调" generate / SillyTavern.* / tavern_events / z 均可用；
   要访问主窗口真实 DOM/全局则用 window.parent.*
```

**发布链路**（作者侧）：
- 前端 bundle 上传 GitHub 仓库（本例 `sanmingyue/tavern_dist`，分支/标签 `tq-v1.0.6`，路径 `dist/汤泉/脚本/零层美化/index.js`）；
- 经 jsdelivr CDN 加速：`https://testingcf.jsdelivr.net/gh/{user}/{repo}@{tag}/{path}`；
- 卡内只存这一行 import URL，其余逻辑（MVU、渲染、存档）都在该 bundle 及其动态 import 依赖里；
- 动态依赖（klona/pinia/Vue/MagVarUpdate bundle）也走 CDN import，见 [09 §33](09-外部接口与功能清单.md)。

> ⚠️ 完整运行模型（隐藏 iframe + 全局注入 + UI 楼层 iframe）见 [14 §57.1](14-从零实现指南.md)。

## 3. 前端控制器架构（零层美化 index.js）

### 3.1 总体形态

- 单文件、无换行的压缩 bundle（约 1.24 MB），Vue 3 + Pinia 构建产物；
- UI 组件以**内嵌 SFC 源码字符串**形式存在（`<template>` 字符串），运行时由 Vue 编译，**不是**动态 import 的真实模块；
- 因此 `index.js` 里的 `import './customerGame'`、`import '../../runtime/mvuRuntime'` 等相对路径只是**源码字符串残留**，没有运行时行为，不要被吓到。

### 3.2 启动流程

```
IIFE 入口
  └─ g.open() 初始化（挂载全局、建 store）
       └─ waitGlobalInitialized('Mvu')  等待 MVU 就绪
            └─ 初始化各 store / 模块
                 └─ 挂载全局：
                     window.parent.tangquanZeroLayer
                     window.parent.tangquanFrontend
                     window.parent.tangquanZeroLayerEmergencyDisable （应急卸载入口）
                 └─ $(window).on('pagehide') 兜底清理
```

卸载时清理 `window.parent.tangquanFrontend` 等全局，防止残留。

### 3.3 核心模块（按功能划分）

| 模块（源码内路径/名称） | 职责 |
|---|---|
| `customerGame` | 游客玩法：顾客经营游戏 UI 与逻辑 |
| `bossEconomy` | 老板玩法：经营经济系统 |
| `dailyArrangementRuntime` | 每日安排运行时（对玩家每日计划做判定） |
| `save/autoSaveController` | 自动存档控制器（见 [04-存档与世界书.md §9](04-存档与世界书.md)） |
| `aiMessageParser` | AI 回复解析（见 [03-正文识别与变量更新.md §7](03-正文识别与变量更新.md)） |
| `customerPrompts` / `waiterPrompts` / `dailyArrangementPrompts` / `aiTalentMarketPrompts` | 各场景的提示词模板 |
| `presetOutputFormat` | 输出格式预设管理（思维链 / 无思维链切换，见 [02-楼层与接口与请求控制.md §6](02-楼层与接口与请求控制.md)） |
| `airpOutputMode` | AIRP（AI 角色扮演）输出模式管理 |
| `worldbookRuntime` | 世界书条目同步（`syncModeEntries`） |
| 楼层同步 | `scheduleBossMvuSync`、`scheduleWaiterGeneratedResultSync`（见 [02-楼层与接口与请求控制.md §4](02-楼层与接口与请求控制.md)） |
| **监听层**（beautifier / zeroLock / 镜像 / 保活） | 事件订阅、DOM 观察、Vue watch、生命周期清理（详见 [07-监听层.md](07-监听层.md)） |

### 3.4 关键常量

- 存档名：`tangquan-save-v1`（正式）、`tangquan-save-v1-staging`（暂存）
- 模式枚举：`z.enum(['未选择', '老板', '游客', '服务员']).catch('未选择')`
- 楼层变量：`activeMode`、`activeSlotId`、`lastSwitchAt` 等
