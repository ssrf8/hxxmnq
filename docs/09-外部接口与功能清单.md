# 外部接口与功能清单（全量审计）

> 本文档是全量审计结果：这张卡的前端（`零层美化/index.js`）调用了哪些外部接口、有哪些容易遗漏的功能/小巧思。
> 审计方法：对 1.24MB minified 单行文件做关键词/字节偏移扫描 + 子代理深挖，结论均带 `index.js` 字节偏移证据。

## 33. 外部接口总览（结论先行）

**这张卡的前端零直接网络请求**：`fetch(`、`XMLHttpRequest`、`WebSocket`、`EventSource`、`Worker(`、`axios`、`importScripts` 全部 **0 命中**。

所有外部 IO 只有 4 类：

| # | 接口 | 数量 | 位置（index.js 偏移） | 说明 |
|---|---|---|---|---|
| 1 | jsdelivr CDN import | 3 | @23（klona）、@116（pinia）静态；@1240049（MagVarUpdate）动态 | ⚠️ **离线化未完成**：index.js 仍指向 CDN，`vendor/` 有本地副本但未被引用 |
| 2 | postimg.cc 图片 | 97 | `Ls` 映射表 @899690 附近 | 场景背景 **day/night 双版本**，img src 加载，无预加载器 |
| 3 | zeabur 立绘 | 1 模板（动态） | `Ws` 函数 + `Gs` 角色哈希表 @899690 | `role-cards/.../characters/...` 按需加载，见 [34.8](#348-立绘哈希映射表gs) |
| 4 | 酒馆 SillyTavern API | — | 散见 | `generate` / `createChatMessages` / `setChatMessages` / `Mvu.parseMessage` / `updatePresetWith` / `getChatMessages` / `eventOn`×8+ / `MutationObserver(#chat)` / `window.parent` 挂载 |

### 33.1. jsdelivr CDN（3 个，未离线化）

```js
// @23 静态 import（文件开头）
import { klona as e } from 'https://testingcf.jsdelivr.net/npm/klona/+esm';
import { createPinia as t, defineStore as n } from 'https://testingcf.jsdelivr.net/npm/pinia/+esm';

// @1240049 动态 import（运行时才加载）
window.parent.Mvu || await import('https://testingcf.jsdelivr.net/gh/MagicalAstrogy/MagVarUpdate/artifact/bundle.js')
```

- `vendor/` 目录已备好本地副本（`klona.js`、`pinia.js`、`magvarupdate.js`、`vue.js` 等），但 index.js 里**仍是 CDN 绝对 URL**（`/npm/` 残留 2 处 = klona+pinia 同一行）。
- **离线化改造 = 把上述 3 处 URL 改为指向本地 vendor/ 文件**，尚未执行。

### 33.2. postimg.cc 图片（97 张，场景背景）

### 33.4. 酒馆接口（外部能力的唯一通道）

所有"联网"都通过酒馆进程代理，前端只调酒馆暴露的 API：

| 能力 | 调用 | 用途 |
|---|---|---|
| AI 生成 | `generate({...})` | 所有模型请求（串行队列，见 [34.1](#341-ai-生成串行队列enqueueaigeneration)） |
| 写楼层 | `createChatMessages` / `setChatMessages` | 回复正文、手动消息落地 |
| 变量更新 | `Mvu.parseMessage(message, parseBase)` | 执行 `<UpdateVariable>` JSON Patch |

| 读历史 | `getChatMessages('1-${last}', {include_swipes:true})` | 历史过滤（见 08 文档） |

| DOM 观察 | `MutationObserver(#chat)` | 视觉镜像层（零层美化）兜底 |
| 跨窗口 | `window.parent` | 挂载 `tangquanZeroLayer`/`tangquanFrontend`/`tangquanZeroLayerEmergencyDisable` |

### 34.4. 导出功能（2 个）

统一走 `Bd`（Blob + `anchor.download` 下载，@1154199）：

```js
function Bd(e, t, n) {  // filename, content, mime
  const a = new Blob([t], { type: `${n};charset=utf-8` });
  const r = URL.createObjectURL(a), o = document.createElement('a');
  o.href = r; o.download = e; document.body.appendChild(o); o.click(); o.remove();
  URL.revokeObjectURL(r);
}
```

1. **导出存档**：`save.exportSlot(slotId)` → `Bd(filename, content, mime)` + `ao('已导出')`（@1152821）；
2. **问题记录导出**：设置面板"问题记录——遇到异常时导出最近 5 次操作"，`exportProblemRecord()` → `未开之花-问题记录-${timestamp}.json`（@422253，用 `log.exportJson` + `makeProblemRecordContext`，给作者排查用的调试功能）。

## 35. 排查方法（如何自己验证遗漏）

1. **外部 URL**：python 正则提取全部 `https://`，按域名分类，比对 postimg(97)/jsdelivr(3)/zeabur(1) 之和 = 101；
2. **网络调用**：搜 `fetch( XMLHttpRequest WebSocket EventSource Worker( importScripts axios sendBeacon`，全 0 即无直接请求；
3. **浏览器功能**：搜 `localStorage sessionStorage clipboard Notification vibrate Audio( speechSynthesis FileReader IndexedDB cookie` 等，判断有无被忽略的能力；
4. **UI 功能**：提取全部 `aria-label="..."`，就是完整界面元素清单（本卡共 44 个）；
5. **事件订阅**：`eventOn\(tavern_events\.(\w+)` 枚举全部酒馆事件；
6. **定时器**：`setInterval / setTimeout( / requestAnimationFrame` 找后台循环。
