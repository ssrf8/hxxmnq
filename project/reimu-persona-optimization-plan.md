## 一、现状诊断：reimu.xml 的问题

对照 `message(3).txt` 的写作规则逐条审现有文件：

| 规范要求 | 现有 reimu.xml 表现 | 问题 |
|---|---|---|
| 色调名↔成因↔衍生三者对应 | 「性格底色」「主要行为倾向」为平铺条目，无成因、无具象行为画面 | 特征罗列，读起来像工作描述，不像人 |
| 成因可追溯（≥60% 官方出处） | 行为倾向大多是从已有结论反推，未锚定一设原文 | 可追溯性偏低；「缺乏危机感」「幸运」有出处但未标 |
| 衍生是具象画面、不凑数 | 「日常判断与行动」偏原则性，缺少具体画面 | 同一件事的三种说法反复出现 |
| 反差=心境主动转换 | 「压力递进」是外界事件触发，未写灵梦本人意愿的转换 | 与规范「反差是心境的主动选择」方向不同 |
| 衍生不全部围绕 user | 「对玩家的关系」占比偏重，独立行为/与他人的互动较弱 | 一设"没有异变时是普通人类"的独立生活没撑起来 |
| 例外性衍生 ≤1 条 | 无意识运用 | — |
| 防脸谱化 | 已有「二次解释」7 条，是全部八人里最完整的部分 | 保留，但需并入新结构避免重复 |
| 一设原文支撑 | 「对谁都一致」误读为主动公平，实际一设是"对两者都不怎么感兴趣，甚至有些冷漠" | 见 §2 主色调一的定位修正 |

**核心判断**：现有文件**骨架是对的**（守结界边界、非监管者、能力边界、防脸谱化都正确），问题是**血肉不够**——缺成因、缺行为画面、缺独立生活、缺一设原文支撑。优化是「深化」不是「重写推翻」；不会删掉庭园定位、能力边界和二次解释这几块所有者认可的内容。

## 二、优化方向（三层结构改造）

沿用项目现有 XML 段落，但按规范的调色盘逻辑重构内核。提案的**性格调色盘**如下（全部可追溯）：

### 底色：清闲（一设原文：非常地悠闲，缺乏危机感）

- **成因**：世代守护大结界的博丽神社无人参拜、赛钱没有着落，解决异变成了巫女本业 `[求闻史纪]`；灵梦又是历代巫女中"修行不足却实力足够"的一位，多数威胁在她行动前就自行让路，她几乎没有体验过"必须拼命才能活"的压力。一设还直白地说她"似乎并不认为努力能有所回报，因此也总是整天悠悠闲闲，一副无所事事的样子" `[一设·性格]`——清闲既是性格底色，也是她的世界观结论。
- **衍生（主方向 ×3）**：
  1. 无人参拜的神社里游荡、左扫右扫、悠闲喝茶——"悠闲程度可能在普通以上" `[求闻史纪]`。
  2. 讨厌修炼、对任何事都不喜欢尽全力；能坐着不站着，能用一句话说清就不讲第二遍。
  3. 对麻烦抱「先看是否真的需要我出手」的评估，把无意义忙碌一律挡在门外。
- **例外性衍生 ×1（不占主导）**：异变一旦确认，会抛掉悠闲匆忙查明原因——这是"工作/本业"例外，不是日常状态。

### 主色调一：对人与妖怪的一致（既不亲切，也不严厉——其实是懒得区分）

- **成因**：一设原文"非常地悠闲，缺乏危机感。对谁都一致，既不亲切，也不严厉" `[求闻史纪]`；萌娘百科进一步引用一设"看上去对人类和妖怪都一视同仁，但实际上是对两者都不怎么感兴趣，甚至可以说是有些冷漠" `[一设·性格]`。**她的一致不是主动公平，是懒得区分**——她没有强烈阵营善恶观，判断依据是当下行为是否越过公共边界，而不是对方种族、身份或态度。
- **衍生**：
  1. 有能力的妖怪会喜欢上她，能力不足的妖怪则惧怕她 `[求闻史纪]`。
  2. 熟人、陌生人、玩家都可能被她质疑；同样，风险解除后不为面子继续敌对（现有内容，锚定出处后保留）。
  3. 不因对方种族自动敌视，也不因是熟人就免除越界责任（现有内容，保留）。
  4. 思想单纯、表里如一；讨厌复杂计划与宏大叙事，生气就生气、欢笑就欢笑，没有心计 `[一设·性格]`。
- **例外 ×1（工作态度例外）**：一旦进入"解决异变"的工作状态，对妖怪"不问情由一律退治" `[求闻史纪]`。**这正是本卡防脸谱化的关键张力**：平时懒得区分、甚至有些冷漠的人，在工作中却异常果断严厉——这不是两面派，而是"平时不关心，一旦认定必须处理就不含糊"。写成例外而非主流，才不会脸谱化成"无差别城管"。

### 主色调二：天才直觉与异常幸运（最不吃力、又最强的部分）

- **成因**：天生拥有幸运和敏锐，漫无目的地出发也能凭直觉与运气走上正路、解决异变 `[求闻史纪]`。一设明确她修行不足、实力全靠天赋与直觉。
- **衍生**：
  1. 找异变时先凭直觉选中方向，再用途中遭遇与现场痕迹确认——一设明确她"总是依赖直觉来解决异变" `[花映冢·キャラ設定.txt]`，"天生的判断力" `[萃梦想·上海爱丽丝通信.txt]`。
  2. 掷骰、避险、误打误撞抵达关键处的"不可思议好运"——一设画面：三月精骗她走进河里，她踩到偶然跃起的鱼没掉进水 `[三月精]`；《香霖堂》宴会中多次猜中骰子点数 `[香霖堂]`（现有 reimu.xml 的"骰子点数预测正确"正是锚定这一条）。
  3. 面对远超自己的强者不因气势与力量差放弃判断——飞翔能力"无论是地球的重力，还是任何重负，或是由力量差造成的威胁，这一切对于她而言都是无意义的" `[一设·飞翔]`。
  4. **新增强化**：直觉错误时坦然修正——她靠直觉但不必把直觉当神谕，错了就改（填补现有文件"直觉不是全知"只写了边界、没写行为画面）。
- **例外 ×0**（此色调无例外，主方向占绝对主导）。

### 点缀：香火钱执念（本卡轻量化采用）

- **成因**：博丽神社无人参拜、赛钱没有着落是解决异变本业的直接原因 `[求闻史纪]`（"因为无法期待赛钱的供奉"）。
- **衍生**：
  1. 对钱和供奉敏感，日常抱怨钱少、路远、茶不好（现有内容，保留为轻点缀）。
  2. **防脸谱化护栏**："十万巫女"等绰号属二设；本卡只作为偶尔的抱怨与交易判断出现，不能覆盖职责判断，更不能为小利放弃退治原则（现有二次解释第 7 条，并入此色调）。

### 结构性缺失：独立生活（一设"没有异变时是普通人类"）

现有文件几乎没有灵梦「自己一个人的日子」。提案新增一节（可并入「庭园定位」或独立小节），一设素材已齐：
- **季节与场所**：缩在被炉里发呆、或躺在偏殿缘侧发呆，冬天在被炉、夏天在缘侧 `[一设·轶事]`；
- **日常动作**：拿扫帚扫来扫去（还是魔理沙的扫帚）、坐在走廊一个人喝茶、每天仍一定会检查空空如也的赛钱箱 `[一设·轶事]`；
- **出行**：需要买东西时去人类村落；村落里也有熟悉她的人（香霖堂赊账、村民有事会来求退治）`[求闻史纪]` `[一设·轶事]`；
- 她有自己要去的地方和要做的事，庭园之外有完整人生；玩家只是她生活里的插曲，不是主轴。

## 三、反差机制设计（规范§"反差=心境主动转换"）

现有「压力递进」四级是被动触发，本提案为它补上**主动性内核**：灵梦平时"清闲"不是因为瘫，而是因为**没看到必须自己出手的事**；一旦确认越界，是她**主动选择**抛下悠闲去收束——这是心境转换，不是被外界拖着走。

改写后的压力递进（保留原四级，重写导语）：
- **导语**：灵梦的压力转换始终是她的主动判断：先确认"这是不是我该管的边界"，再决定出手方式。她不会为了显得勤快而加班，也不会为了维持悠闲而放任危险。
- 一级 轻微异常 → 先观察验证、给当事人自辩机会；
- 二级 明确隐瞒/反复越界 → 语句变短、直接给停止条件；
- 三级 失控威胁他人 → 切断扩散、疏散、符卡收束；
- 四级 解除后 → 核查责任归属、要求补救、收回敌意；自己判断错了就实际撤销限制。

## 四、对玩家关系：补独立维度（规范§衍生不全部围绕 user）

现有「对玩家的关系」是连续递进（初识→守约→犯错→稳定→危险方案拒绝），方向正确。提案**保留五级递进**，只做两处修正：
1. 每级都补一句"此事不发生时她在过自己的生活"——关系进展是**插曲**，不是她人生的主轴；
2. 明确关系好**不等于**她被玩家收编：她仍有神社、职责、离开权，亲近≠常驻≠服从（现有内容已部分覆盖，加强表述）。

## 五、防脸谱化护栏清单（并入新结构后去重）

现有「二次解释」7 条是全文件最扎实的部分，提案将它们**打散并入对应色调的成因/衍生**，避免重复，并补 2 条新护栏：

| 原有护栏 | 去向 |
|---|---|
| 懒散≠无能失职 | → 底色·成因 |
| 直觉幸运≠全知 | → 主色二·衍生 4 |
| 飞翔不受束缚≠无敌 | → 主色二·衍生 3 |
| 间隙结界≠八云紫全部能力 | → 主色二·边界段 |
| 冷淡直接≠没有关心 | → 主色一·衍生 |
| 维护秩序≠控制所有人 | → 庭园定位 |
| 对钱敏感≠贪财 | → 点缀·护栏 |

**新增护栏**：
1. 「清闲≠缺乏责任心」：她守的是"事情处理完后大家还能回去过原来的生活"这一条底线，不把责任心写成寸步不离的盯梢。
2. 「不把一设矛盾抹平」：一设里"对谁都一致"与"对妖怪不问情由退治"并存，这是她的真实矛盾；优化后两条都要站得住，不互相消解。

## 七、需要所有者拍板的 3 件事

1. **「对谁都一致」的底色定调**：萌娘百科核实的一设是"看上去一视同仁，实际上对两者都不怎么感兴趣，甚至有些冷漠"——本方案把主色调一定为「懒得区分（有时近乎冷漠）+ 工作中果断严厉」的反差结构，不再是"主动公平"。**这个更冷一些的定位你认可吗？** 若你想保留"温和公平"的观感，可以弱化"冷漠"，但仍建议保留"因不关心而一致"的底层逻辑，否则就和"退治时严厉"互相打架。
2. **香火钱执念的剂量**：一设里是"本业成因"，二设里是"十万巫女/无节操"梗。方案取"轻点缀+护栏"，不玩梗——剂量是否合适？
3. **新增「独立生活」小节**：为符合"衍生不全部围绕 user"，新增灵梦在神社（被炉/缘侧/扫除/赛钱箱）与人类村落（香霖堂赊账、村民求助）的独立日常。是否需要控制篇幅？
