# 弹幕 BGM · R2 接入模板

当前界面与播放总线已经落地，但不附带音乐文件。曲目登记位于 `src/battle/battle-bgm-catalog.json`。

## 网易云音乐多链接方案（阶段 1 已接入）

目标是让玩家在本机为「道中／Boss／角色对战」分别维护多条音乐链接；列表、顺序、音量与启用状态只写入浏览器 `localStorage`，不进入 MVU、聊天记录或角色卡状态。BGM 默认关闭，默认音量为 8%。

### 预定的数据边界

```text
gensokyo-garden:battle-bgm-playlists.v1
  stage_theme | boss_theme | duel_theme
    - { id, source_url, source_kind, title_hint, enabled }
```

- 每类最多 12 条，按本地顺序轮播；重复 URL 去重，空值和非 HTTPS URL 拒绝保存。
- 接受多条网易云分享页链接作为本地歌单记录，也接受浏览器可直接播放的 HTTPS 音频地址。
- 普通网易云歌曲／歌单页不是可假定能被 `<audio>` 直接播放的音频源；运行时必须实际尝试播放，失败时标记“当前环境不可播放”，并跳过到下一条，不伪造播放成功。
- 不抓取网页、不绕过登录、地区、会员、DRM 或跨域限制；不保存 Cookie、Token、账号或任何密钥。

### 当前已接入的范围

- 战斗音频设置中已提供三类战斗 BGM 的本地多行链接输入，每类最多保留 12 条，自动去重并写入浏览器 `localStorage`。
- 已识别网易云音乐的歌曲与歌单分享链接（含 `#/song?id=`、`#/playlist?id=`）。单曲使用网易云公开的 `song/media/outer/url?id=` 跳转地址作为浏览器播放候选；歌单作为本地收藏保存，并提供“打开网易云歌单原页”。
- 仅浏览器实际可以播放的 HTTPS 音频链接与网易云公开单曲跳转会接入当前 BGM 总线；不抓取网页、不解析受限流，也不会绕过登录、会员、地区或 DRM 限制。
- 音乐来源分为“关闭／作者推荐／自己想听”。作者推荐固定使用 `1826992588`、`2752778648`、`3357653408`、`539928216` 四首网易云单曲，以伪随机顺序轮播；四首均播放过后才重新洗牌。播放错误自动跳过当前曲目。
- 正式战斗与弹幕演练各会在首次进入时暂停一次并打开音乐说明；提示只保存在本机，之后不会重复出现。

### 分阶段交付

1. **本地歌单 UI**：在现有战斗音频设置中添加三类曲目的多行输入、添加／删除／排序、启用开关和“本机保存”提示。
2. **播放兼容层**：保留现有 R2 直链模式；新增多条本地候选的轮播与播放失败回退。分享页链接只作为可验证候选，不能播放时给出明确状态和“打开原链接”按钮。
3. **验收**：验证刷新后本地恢复、12 条上限、重复链接、无效 URL、播放被浏览器拦截、跨域／地区限制、曲目切换、战斗暂停／恢复及 320px 窄屏。

实施前的唯一产品决定：如果要“在战斗中稳定播放”，应以用户拥有授权的可直接播放 HTTPS 音频地址为正式支持目标；网易云页面链接则作为本地收藏与跳转入口，除非它在当时浏览器环境中被实际验证可播。

后续上传到 Cloudflare R2 后，只需把对应曲目的 `source_url` 从 `null` 改为公开 HTTPS 对象地址或自定义域名地址，例如：

```json
{
  "id": "boss_theme",
  "title": "符卡决战",
  "description": "适合妖花核心与正式 Boss 战的循环曲。",
  "source_url": "https://media.example.com/gensokyo/bgm/boss-theme.ogg"
}
```

约束：

- 只接受公开 `https://` 音源，不在前端保存 R2 Access Key、Secret 或签名凭据。
- 建议使用 `.ogg` 或 `.mp3`，开启浏览器可读取的正确 `Content-Type`。
- R2／自定义域名需允许当前 SillyTavern 页面来源读取音频；跨域失败时界面会保留设置但静默不播放。
- 曲目默认循环；音量和曲目选择只保存在浏览器本机，不写入 MVU。
