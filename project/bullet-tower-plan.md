# 符卡之塔实施规划

## 已实施的首版合同

- 一次入塔建立仅存在于当前 UI 会话内的三层顺序；琪露诺、爱丽丝、咲夜每轮使用 Fisher-Yates
  随机排列，退出、刷新或取消战斗即丢弃顺序和当前层数，不做断点续爬。
- 三层基础数值固定递增。角色主题、战斗图集和 S0／S1／S2 cut-in 仍归对应 Boss；随机只改变
  守关顺序，不会把角色素材串用。
- 每层结束都先调用现有的本地可信副本结算：`settlement_id` 写入 `battle.rewarded_ids` 并复读后，
  才允许胜利进入下一层。因此崩溃或退出最多丢失当前未完成层，已结算奖励不会重复或消失。
- 胜利（`clean_win`／`narrow_win`）进入下一层；失败同样立即结算既有失败奖励，然后本轮结束。
- 保留现有杂鱼标签获取规则：角色对战失败增加、胜利减少；符卡之塔失败同样在本层可信结算中
  增加一枚。爬塔胜利不消耗标签。失败奖励始终按失败前的标签数计算，随后才写入 `+1`，同一
  `settlement_id` 的重试不会重复增加。

## 杂鱼标签

| 标签数 | 本层难度 | 奖励倍率 |
|---:|---|---:|
| 0 | 标准 | 100% |
| 1 | 放缓 | 85% |
| 2 | 缓和 | 70% |
| 3+ | 援助（封顶） | 55% |

奖励按原有 `clean_win=12`、`narrow_win=8`、`loss=3` 乘倍率后向下取整，最低为 1 金币。
标签同时减少 Boss HP、敌弹速度、弹量／杂鱼波频率，并在 2 枚以上增加生命与 Bomb；所有值仍通过
原有参数白名单钳制。

## 后续验收

1. 在真实 SillyTavern 连续完成至少两层、退出一轮并刷新，确认已结算层只入账一次、未完成层不恢复。
2. 以 0／1／2／3+ 标签分别验证 UI 文案、数值压力和 `12/10/8/6` 的胜利奖励梯度。
3. 检查暂停、音频设置、Escape 和触控取消都不会让后台战斗继续推进，也不会保留塔进度。
