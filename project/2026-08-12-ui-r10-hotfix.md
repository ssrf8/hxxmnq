# production UI r10 热修复

## 变更

- GAL 的普通请求、异变收束和胜利要求在任意生成错误后统一停止当前 generation，并释放宿主忙碌、事务协调器与界面发送锁。
- GAL 发送同行增加“修复”按钮，允许玩家手动释放发送锁；强制释放会拦截迟到生成结果，避免旧回复落入新事务。
- 新手教程第五步同时从正式事件和 2 点灵感资源事实派生，避免地图已进入清理旧地基阶段但教程仍停在上一阶段。
- 每次角色符卡胜利先覆盖旧的胜利要求；生成中点击放弃会先停止请求、释放 GAL 锁，再清除本次要求。该路径不增加杂鱼标签，也不回滚已经结算的战斗。
- 幻想乡案内进入画廊前同步关闭 launcher；单纯点击角色打开操作小窗不再被当作聊天进行中。
