# 0.2.0-r45 所有者验收清单

> 验收对象：`幻想乡物语·移动庭园（测试检查点 0.2.0-r45）`
>
> 快进入口：移动庭园右上角“诊断与恢复” → “测试快进”。每个按钮都会直接写入并复读 MVU，不发送消息、不调用 LLM；按钮之间互相独立，会覆盖当前测试状态，建议每批使用一个新聊天。

## A. 导入与基础壳

- [ ] 导入 R45 JSON，确认角色名和世界书版本均显示 `0.2.0-r45`。
- [ ] 新建聊天，移动庭园界面只挂载一份；开场设置仍可正常确认。
- [ ] 打开“诊断与恢复”，确认共有 9 个快进按钮。
- [ ] 刷新、Swipe 或切换聊天后没有重复界面、空白界面或原生输入区永久消失。

## B. 开放庭园与施工

1. 点击“跳至开放庭园（设施未建）”。
2. 返回庭院，打开“开放庭园”。

- [ ] 页面说明教程已结束，后续没有必须完成的主线。
- [ ] 妖精花园、月见温泉、宴会广场都显示三个具体方案。
- [ ] 任选一个施工按钮；点击时不调用 LLM，物资和时段由代码结算。
- [ ] 建成后设施在地图及机会面板中可进入，且不能重复施工。

## C. 自定义异变卡

1. 在新聊天点击“跳至异变卡验收”。
2. 打开背包，使用异变触发卡；填写例如“所有人互换身体”的规则。

- [ ] 背包初始有 3 张异变卡。
- [ ] 玩家可填写标题、规则、影响范围、表现倾向和排除内容；不能自建普通物品。
- [ ] 生成成功后才扣卡；停止生成或回执失败会退卡。
- [ ] 普通聊天、设施剧情和多人场景持续携带异变影响。
- [ ] UI 不显示隐藏源头；每日调查只逐步显示线索。
- [ ] 活动异变期间不能主动提前结束。

## D. 七日收束

1. 在新聊天点击“跳至异变第 7 日收束”。
2. 返回“开放庭园”，点击异变收束入口。

- [ ] 状态显示已到收束阶段，不再要求手动推进 28 个时段。
- [ ] 收束剧情由灵梦寻找并处理源头，完成后异变进入历史。
- [ ] 本轮对话在点击“结束剧情”前仍保持异变影响；之后的新回复不再携带该影响。

## E. 三设施与换型

1. 在新聊天点击“跳至三设施全建成”。
2. 打开“开放庭园”。

- [ ] 三座设施均已建成，每座三个形态全部解锁。
- [ ] 可以在非当前形态上选择装修；施工角色由代码锁定，失败会退款。
- [ ] 装修完成后当前形态、地图入口和三个快捷行动同步变化。
- [ ] 妖精花园风险行动的异常/损坏由本地稳定 roll 决定，不接受 LLM 篡改。
- [ ] 月见温泉可选择公开、仅邀请、独处；宴会可安排当前至未来 4 个标准时段。

## F. 来访、邀请与活动

1. 在新聊天点击“跳至来访与活动验收”。
2. 查看地图和开放庭园机会面板。

- [ ] 地图显示灵梦、魔理沙、爱丽丝三名在场角色；没有玩家占位小人。
- [ ] 全部登记角色均已认识，可测试邀请的接受、改期或拒绝。
- [ ] 普通场景最多 3 名访客；宴会活动最多 6 名。
- [ ] 温泉邀请制只能点名当前已经到场的角色。
- [ ] 邀请制宴会由玩家点名对象，不把“改期”误算成已接受。
- [ ] 时间由 LLM 返回的 MVU 时段更新推进，到点来访和宴会由代码触发。

## G. 道具与设施恢复

1. 在新聊天点击“跳至道具与设施修复”。
2. 打开背包、进入任意自由聊天，再回开放庭园修复妖精花园。

- [ ] 背包有糖果包、月见茶、温泉香包、宴会食盒、鬼酒和 3 个修缮包。
- [ ] 聊天输入区可选择一个道具供“下一回复”使用；回复成功后才扣除。
- [ ] 同一场景最多保留 3 种道具影响，后来进入的角色只能得知可观察到的结果。
- [ ] 点击“结束剧情”后，道具影响在收尾回复完成后彻底清除。
- [ ] 妖精花园初始为损坏；使用修缮包可以代替 2 物资，失败时会恢复预留。

## H. 回归与失败恢复

- [ ] 任意固定结算重复点击不会重复扣资源、重复推进时间或重复发奖励。
- [ ] 生成中停止、续写、Swipe 和重新生成不会制造第二份本地事务。
- [ ] 普通 LLM 回复不能覆盖金币、物资、背包、设施、访客、异变源头和活动状态。
- [ ] 约 320px 宽度下按钮可换行、文字可读、没有横向裁断；键盘可以访问所有按钮。
- [ ] 若出现失败，记录所用快进按钮、操作顺序、可见错误、当前聊天文件和控制台错误。

## 通过标准

- A 必须通过；B—G 每批至少使用独立新聊天完成一次。
- 任何重复扣费、隐藏源头泄露、异变提前消失、活动人数越界或 MVU 复读失败均视为阻断问题。
- 离线测试通过不等于实机验收通过；完成本清单后再把 R45 标记为 accepted。
