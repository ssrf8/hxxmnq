## 1. 素材来源裁定（重要，先于一切美术工作）

核实结果：`GensokyoClub/th06` 是东方红魔郷 1.02h 的 **C++ 反编译源码仓库，不含任何游戏贴图**，
README 明确要求使用者自备原版 `東方紅魔郷.exe`。"贴图直接拿下来用"不成立——仓库里没有；
即使从原版游戏数据中抽出 etama 弹图，也属于 ZUN 原始素材再分发，违反东方二创指引，
且违背交接文档既有裁定（"只取机制与数学，不取其 etama 弹图/ECL/资源"）。

**因此素材策略为：**

1. `th06` 反编译代码继续当**规格书**用：弹种家族与尺寸表、颜色循环、item 抛物线与 POC 行为、
   BulletManager 的 spawn 特效时序、魔法阵/击破演出的帧节奏——只抄数值与语义。
2. 弹幕、道具、妖精与 Boss 战斗 sheet 继续走项目已有自绘管线（chroma 底稿 →
   透明 `*-v1.png` → `asset-manifest.json` 登记 → 仅透明版进产物）。**S0／S1／S2 cut-in
   立绘是明确例外**：按所有者提供的原文件直接登记、复制和内嵌，不抠图、不去背、不修改
   透明通道、不生成 chroma/alpha 中间稿。
3. 新增素材一律放 `src/assets/battle/**`（协议白名单）；图集命名沿用 `*-sheet-v1.png`，
   S0／S1／S2 立绘则按 `portrait-<boss_id>-s<0|1|2>-v1.png` 分文件命名。

## 2. 分对象美化方向

### 2.1 弹幕（新增 `battle-bullets-sheet-v1.png`）

- 专用弹幕图集，网格排布：**弹种家族 × 8 色相** 直接烘焙成帧（TH06 做法），避免运行时染色。
  家族对齐现有 7 shape 并补齐常用位：小玉、中玉、大玉（bubble）、米弹（rice）、鳞弹（pellet）、
  苦无（kunai）、札弹（crystal/card）、花瓣（petal）、星弹、光珠。新增形状必须同步扩展
  `BulletShape` 联合类型与几何 fallback，不允许只有贴图没有降级。
- 视觉结构统一为三层：白芯 + 饱和主色体 + 半透明外晕（描边收窄）。几何 fallback 同步改为
  「白芯 + 主色」双层，替换现在的单色平涂，保证断链时观感不塌。
- 删除现行「几何弹上再叠 atlas 装饰」的双重绘制：atlas 命中则**只画贴图**，未命中才走几何。
- 消弹演出：Bomb / 阶段击破时把 `cancelling` 弹替换为消弹星屑帧（缩放 + 旋转 + 淡出，
  ≤ 现有粒子上限 128，不新增碰撞）。
- 出膛已有 materialize 缩放，补一帧短促 spawn 光圈（0.09s 内淡出），对应 TH06 出膛闪光。
- 危险度表达维持「形状 + 颜色」双通道（协议 P1.3），图集烘焙天然满足。

### 2.2 P点掉落（并入 `battle-bullets-sheet-v1.png` 或独立 item 区）

- P小（红底白 P）/ P大（红金、约 1.5×）专用帧；上抛下落段做 4 帧水平翻转（TH06 item 翻面感）。
- 磁吸（POC / 满 power 上半区）时加 2~3 个拖尾光点（复用粒子系统，计入上限）。
- 收集反馈：canvas 浮字 `+1` / `+8`（0.4s 上飘淡出，纯绘制不进 DOM），Power 条同步微闪。
- 满 power 后掉落转为分数语义时（若后续做），帧换蓝色点数 item——本轮只预留网格位。
- POC 提示：玩家进入自动收取带时，顶部画一条 1px 微光带 0.3s，教学成本为零。

### 2.3 小怪（新增 `battle-fairy-sheet-v1.png`）

- 妖精 sprite：64px 底稿，2 帧翅膀扇动；**按掉落物配色变体**——蓝妖精=P小、金妖精=P大，
  掉落预期可视化（TH06 惯例）。
- 入场 0.2s 淡入 + 现有 bob 摆动保留；受击 1 帧加亮（additive 提亮，不换帧）；
- 死亡演出：小型星屑 burst（fx_spark 已有）+ 掉落物从尸点弹出小弧线（模拟已有 item 抛物线，
  只调初速）。
- 血条 tick 保留但改为受击后 1.2s 内才显示，减少常驻噪点。

### 2.4 大怪（boss 形象拆分 + 通用演出层）

**形象拆分**（当前最大违和点）：每个配置有自己的 boss 形象，`config` 增加表现字段
`boss_id`（进配置校验白名单，纯视觉，不进 MVU schema、不进 BattleResult）。阵容建议
（优先复用已有角色底稿风格，新绘战斗姿态帧）：

| 配置 | 主题 | boss 人选 | 依据 |
|---|---|---|---|
| greenhouse_flower_core | 温室妖花 | 保留花核形态；P2 符卡阶段显出**花之精人形** | 主线剧情既定 |
| fairy_pattern_practice | 妖精弹幕练习 | 琪露诺（cirno 底稿已有） | 妖精题材、冰弹配色现成 |
| forest_magic_residue | 森林魔力残响 | 爱丽丝（alice 底稿已有；备选 mystia） | 森林魔法使、人偶可当僚机弹源 |
| boundary_echo_trial | 境界回声试炼 | 十六夜咲夜（sakuya 底稿已有） | laser_warning 刻线 + kunai 弹 = 飞刀/时停语感 |

每 boss 战斗 sheet 需求：待机浮游 2 帧、施法 1 帧、击破 1 帧（沿用现行 2×2 网格约定即可）。

**通用演出层**（一次实现，四场共用）：

- 符卡阶段 boss 脚下旋转魔法阵（半透明，reduced-motion 降级为静态圆环）。
- 受击反馈改为 additive 提亮 ≤2 帧（保留"不换帧、伤害读血条"的现行裁定）。
- 阶段击破：全屏消弹波（星屑化）+ 0.15s 白闪（reduced-motion 时只消弹不闪）。
- 符卡宣言：左上滑入横幅「符卡名 + 小头像」，1.5s 后收起；替换现在的纯文字标题。
- boss 血条下加剩余阶段星标（TH06 式 ★★☆）。

### 2.5 每阶段美少女立绘（宣言 cut-in + 战损差分）

**机制设计**（纯视觉层，只读 phase 事件，不碰结算）：

- 阶段（符卡）宣言时：右侧滑入半身立绘 cut-in，斜切光带扫过，约 1.2s 后退场。
- 阶段被击破时：立绘以「玻璃碎裂闪光」切到下一战损状态，随消弹波一起出现。
- 玩家胜利结算画面：显示最终战损立绘 + 符卡取得结果列表。

**战损分级（尺度裁定，写死在美术规格里）**：

- S0 完好 → S1 轻损（帽饰脱落、衣角撕裂、灰尘划痕）→ S2 重损（袖口/裙摆破口、发型散乱、
  外套滑落、狼狈表情）。
- **尺度锚定在"战损狼狈"，不做裸露、内衣特写或性暗示构图。** 这些角色形象普遍低龄向，
  本卡也需要保持可分发性；"爆衣"的演出爽点由「华丽衣装逐阶段碎裂 + 表情差分 + 碎裂闪光」
  给足，不靠露出。此裁定为硬约束，后续执行 agent 不得放宽。
- 阶段多于战损档位时（boundary/forest 为 4 阶段），中间阶段用**表情差分**（同战损状态换表情）
  过渡，素材量不翻倍：S0(P1) → S0表情差分(P2破) → S1(P3) → S2(最终破/结算)。
  2 阶段配置则 S0(宣言) → S1(P1破) → S2(终破)。

**素材规格与体积预算**：

- 每 boss 直接使用 S0／S1／S2 三张完整图片；不要求合并立绘 sheet。3:4、384×512
  仅作为推荐交付尺寸，不得为满足该建议而裁切、缩放或重新编码所有者原图。
- S0／S1／S2 不要求量化压缩。构建时记录实际体积并评估检查点总量即可；不得以体积预算为由
  自动改图。运行时使用 `contain` 适配 cut-in 区域，并保留图片自带背景或透明通道。
- 三张图按稳定命名进入 manifest 和 data URL 链，输入原文件哈希应与维护源一致；这组素材不设
  chroma/alpha 双份，也不应用透明边、隐藏 RGB、色键转换或背景清除门禁。

### 2.6 场景与 HUD

- 每配置主题背景（低成本两层：暗色渐变底 + 主题粒子慢速下落/漂浮）：
  妖精=雪晶、森林=光叶、境界=细刻线网格、温室=花瓣。粒子计入现有上限，视觉 only。
- 背景亮度必须压在弹幕对比度之下（TH06 铁律：看得清弹 > 背景好看）。
- 现有扫描线保留但调淡；boss 位置指示条、Power 条、残机/Bomb 文字行保留。
