# 庭园导航与不可行走蒙版合同

> 状态：2026-07-30 已接入维护源、离线预览与自包含构建；真实 SillyTavern 运行时验收仍待执行。
> 范围：只管理庭园地图来访角色的本地巡游，不改变 `presence_snapshot`、区域归属、剧情状态或 MVU 字段。

## 1. 目标

角色可以在所属区域附近进行较大范围的二维巡游，但脚底和整段路线不得进入登记的不可行走区域。当前 V1 蒙版覆盖 V3 底图下方的河道与池面，并为红桥桥面保留透明通道。

这是一张**不可行走蒙版**：

- 透明像素：可行走；
- `alpha >= 128`：不可行走；
- 颜色只用于调试辨识，运行时判定只读取 alpha；
- 当前阻挡色为洋红 `#ff00ff`；
- 默认游戏画面不绘制蒙版。

当前 V1 只承诺河道与池面阻挡。主屋、树木、岩石和动态设施尚未登记为不可行走区，不得在文档或验收报告中宣称已经覆盖。

## 2. 资产合同

| 字段 | 当前值 |
|---|---|
| 底图 | `src/assets/maps/garden-base-owner-v3.png` |
| 蒙版 | `src/assets/maps/garden-no-walk-mask-v1.svg` |
| 画布 | `1672×941`，必须与底图一致 |
| Manifest 键 | `maps.garden_no_walk_mask` |
| Runtime role | `non-walkable-alpha-mask` |
| Alpha contract | `transparent-walkable-alpha-gte-128-blocked` |
| 桥面 | 使用 `fill-rule="evenodd"` 在水域阻挡形状中镂空 |

修改蒙版时不得改变画布、底图坐标系或透明/阻挡语义。扩大岸线阻挡区时必须同时检查桥面净宽，不能用整块水域形状把桥重新封死。

## 3. 运行时判定

`src/ui/garden-navigation.ts` 在浏览器中把蒙版加载到离屏 canvas，并提供统一的归一化坐标判定：

1. 脚底中心加周围八点，共九点采样；
2. 默认脚底半径为底图像素 `12×7`；
3. 路径按最多约 8 个底图像素的间隔连续采样；
4. 任一脚底采样点落入阻挡 alpha，整条候选路线即被拒绝；
5. 蒙版未完成加载时暂时放行；加载或解码失败时标记 `failed-open`，避免整张地图被误锁死。

`SpriteActor` 每次准备移动时最多重新抽取 12 条候选路线。全部被拒绝时角色留在原位并进入下一轮休息，不穿越水面，也不进行自动寻路或瞬移。

## 4. 巡游范围

角色仍以 `presence_snapshot.character_views[*].area_id` 对应的区域锚点为中心。2026-07-30 扩大后的参数为：

| 类型 | 纵向半径 | 单次最短距离 | 单次最长距离 |
|---|---:|---:|---:|
| 步行 | `0.105` | `0.045` | `0.120` |
| 浮游／飞行 | `0.120` | `0.045` | `0.120` |

各角色横向半径：

| 角色 | 横向半径 |
|---|---:|
| 灵梦 | `0.150` |
| 魔理沙 | `0.170` |
| 琪露诺 | `0.165` |
| 爱丽丝 | `0.145` |
| 米斯蒂娅 | `0.160` |
| 萃香 | `0.150` |
| 荷取 | `0.160` |
| 咲夜 | `0.148` |

移动速度、`rest → turn → travel → settle` 状态机和 reduced-motion 回退保持不变。扩大的是活动空间和单段路程，不是移动速度。

## 5. 多角色与坐标一致性

同一区域的角色按角色 ID 排序并使用稳定的归一化分槽。分槽偏移同时参与绘制和导航判定，不再使用只存在于最终绘制阶段的屏幕像素错位。

地图缩放、浏览器 DPR、相机拖动和窄屏裁切只改变渲染换算，不改变蒙版坐标，因此同一路线在桌面、移动端和不同缩放下必须得到相同判定。

巡游偏移、当前局部目标和分槽均为 iframe 内存中的 UI 临时状态：

- 不写入 `stat_data`；
- 不修改 `presence_snapshot`；
- 不改变角色正式区域；
- 离场、换区或 reduced motion 启用时回到区域锚点。

## 6. 构建与宿主链

`scripts/build-ui.mjs` 必须：

1. 校验蒙版登记存在；
2. 校验画布与底图一致；
3. 校验 alpha 合同、洋红阻挡形状和桥面镂空合同；
4. 把 SVG 复制到离线预览资产目录；
5. 以 `data:image/svg+xml;base64,...` 嵌入自包含运行产物。

`src/runtime/ui-host-shell.js` 通过 `data-map-no-walk-mask-src` 对应的 dataset 把嵌入资源交给 iframe。正式运行不得依赖开发服务器、本机路径或远程 URL。

## 7. 调试与验收

离线预览 URL 追加 `?gardenMaskDebug=1` 时，地图会以半透明洋红显示阻挡区。该参数只用于开发验收，不写入游戏状态。

canvas 暴露两项只读诊断：

- `data-navigation-mask`：`loading | ready | failed-open`；
- `data-navigation-samples`：内置陆地、河面、桥面三点的采样结果。

最低验收门：

1. `npm run check:ui`；
2. `npm test`；
3. `npm run build:ui`；
4. 离线浏览器确认 `ready`；
5. 内置采样为 `land:walkable,river:blocked,bridge:walkable`；
6. 开启调试层，目视确认洋红区贴合河道且不覆盖桥面；
7. 真实 SillyTavern 中复核长时间巡游、多人同区、缩放、拖动、窄屏和 reduced motion。

截至 2026-07-30，类型检查、UI 构建和全量测试 `161/161` 已通过；离线浏览器三点采样符合合同。真实 SillyTavern 运行时仍是未关闭的最终验收门，未经该验收不得把状态写成 runtime validated。
